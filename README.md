# FYUG Political Science Study Hub

A responsive, browser-based study website for Assam University BA FYUGP (NEP 2020) Political Science.

## Included
- Dashboard and searchable subject library
- DSC 101: Introduction to Political Theory — syllabus topics transcribed from uploaded syllabus
- DSC 102: Indian Government & Politics — syllabus topics transcribed from uploaded syllabus
- Understanding India subject placeholder pending a readable syllabus copy
- Subject tabs for syllabus, detailed notes, 2-mark answers, 10-mark answers, and previous-year questions
- Revision checklist saved in the browser's local storage
- Mobile-friendly layout

## Important content status
This is the initial website scaffold. Detailed notes and model answers still need to be written. No questions are falsely labelled as official PYQs; add original papers or verifiable sources before tagging questions by year.

## Publish with GitHub Pages
In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, and save. Once the deployment finishes, the site should be available at the repository's GitHub Pages URL.
